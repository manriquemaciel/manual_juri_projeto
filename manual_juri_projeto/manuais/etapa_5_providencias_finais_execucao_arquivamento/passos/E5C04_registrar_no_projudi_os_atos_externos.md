# E5C04 — Registrar no PROJUDI os atos externos

## Regra de rastreabilidade

Toda providência relevante realizada no BNMP 3.0, SEEU, SNGB ou outro sistema deverá ficar comprovada no processo de conhecimento.

Usar, conforme o caso:

- juntada do comprovante;
- certidão circunstanciada;
- registro do número da execução;
- identificação da guia/documento emitido;
- data da providência e sistema utilizado.
