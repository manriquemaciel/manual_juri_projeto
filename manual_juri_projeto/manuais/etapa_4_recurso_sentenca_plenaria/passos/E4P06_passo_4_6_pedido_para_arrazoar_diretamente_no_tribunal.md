# E4P06 — Passo 4.6 — Pedido para arrazoar diretamente no Tribunal

## Alerta

Procurar no recurso requerimento expresso como “apresentação das razões na superior instância” ou referência ao art. 600, §4º, do CPP.

Se houver:

- **não abrir** prazo para razões no primeiro grau;
- preparar a remessa;
- a vista para razões ocorrerá no Tribunal.
