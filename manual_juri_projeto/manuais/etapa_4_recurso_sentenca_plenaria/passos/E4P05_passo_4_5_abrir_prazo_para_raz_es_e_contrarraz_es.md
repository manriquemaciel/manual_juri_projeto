# E4P05 — Passo 4.5 — Abrir prazo para razões e contrarrazões

## Prazos

- apelante: **8 dias** para razões;
- apelado: **8 dias** para contrarrazões.

Havendo assistente de acusação, o material registra prazo de **3 dias** para arrazoar após o Ministério Público.

Para a Defensoria Pública, observar intimação pessoal e prazo em dobro.
